Getting Started

Use JWT to authenticate and call endpoints. Create a token via /api/v1/users/token/, then include it as Authorization: Bearer <access_token>.

Authentication

POST /api/v1/users/token/
Body: { "username": "your_user", "password": "your_pass" }
Response includes access and refresh tokens.

Fetch Web Data

GET /v2/fetch

The fetch endpoint allows you to retrieve the full rendered HTML content of any webpage. It handles JavaScript execution, CSS rendering, and complex cookies automatically. Use this for single-page applications (SPAs) or sites requiring heavy browser interaction.

Request Parameters

url string Required

The absolute URL of the page you want to scrape. Must include protocol (http/https).

render_js boolean Default: true

Wait for the page to finish executing JavaScript before returning the content.

proxy_country string

ISO 3166-1 alpha-2 country code for the egress IP address (e.g., 'US', 'GB', 'DE').

Response Object

Property Type Description
content string The raw HTML content of the page.
status integer HTTP status code returned by target.
metadata object Includes response time and proxy info.

Execute Script

POST /v2/execute

Evaluate a small JavaScript snippet in the page context and return a value.

url string Required

The page to open before executing.

script string Required

Example: document.querySelector('h1').innerText

Capture Page

POST /v2/capture

Capture a screenshot (viewport or full-page) and return base64-encoded image data.

url string Required

Target page to capture.

full_page boolean Default: false

Capture entire page including content below the fold.

Proxy Status

GET /v2/proxy/status

Returns proxy pool health and country coverage for the current account. 

import requests

# API Configuration
url = "https://api.scrapyx.io/v2/fetch"
headers = {
    "X-API-KEY": "YOUR_API_KEY"
}
params = {
    "url": "https://example.com",
    "render_js": True,
    "proxy_country": "US"
}

# Execute Request
response = requests.get(url, headers=headers, params=params)

# Output results
print(response.json()['content'])

import fetch from 'node-fetch';

const apiUrl = 'https://api.scrapyx.io/v2/fetch';
const params = new URLSearchParams({
  url: 'https://example.com',
  render_js: 'true',
  proxy_country: 'US',
});

const res = await fetch(`${apiUrl}?${params.toString()}`, {
  method: 'GET',
  headers: { 'X-API-KEY': 'YOUR_API_KEY' },
});

const data = await res.json();
console.log(data.content);

curl -G "https://api.scrapyx.io/v2/fetch" ^
  -H "X-API-KEY: YOUR_API_KEY" ^
  --data-urlencode "url=https://example.com" ^
  --data-urlencode "render_js=true" ^
  --data-urlencode "proxy_country=US"
